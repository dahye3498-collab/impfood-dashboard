# 정육 자동수집 (Google Apps Script → GitHub)

식약처 API가 **해외 IP를 차단**해서 GitHub Actions(미국)로는 정육 수집이 안 된다.
그런데 **Google Apps Script는 구글 서버에서 돌기 때문에 식약처 API에 접근이 된다**(구
GAS+구글시트 시스템이 이 방식으로 자동수집했다). 그래서 GAS가 매월 식약처 API를 호출해
**GitHub 저장소의 `data/quarantine-<연도>.json`을 직접 커밋**하게 하면, **로컬 PC·윈도우
예약작업 없이 완전 자동**이 된다.

- `Code.gs` — 수집기 (식약처 API 호출 → impfood 형식 JSON 생성 → GitHub 커밋)
- 부산물은 건드리지 않는다(해당 월의 **정육만** 교체). 부산물은 계속 `parser.html`로 반영.
- 산출물은 로컬 `scripts/collect.mjs`와 **동일한 형식·정렬**(검증 완료).

## 셋업 (최초 1회, 약 10분)

1. **GitHub 토큰 발급**: 파인그레인드 토큰, **이 저장소만 · Contents: Read and write**
   (parser.html 것과 별개로 하나 더 만들면 됨. 만료일 지정 권장)
2. **Apps Script 프로젝트 생성**: <https://script.google.com> → 새 프로젝트
   → `Code.gs` 내용 전체를 붙여넣기
3. **토큰 등록**: 프로젝트 **설정(⚙) → 스크립트 속성 → 속성 추가**
   → 이름 `GH_TOKEN`, 값 = 발급한 토큰
4. **시간대**: 설정 → 시간대 **(GMT+09:00) 서울**
5. **트리거 등록**: 함수 목록에서 **`트리거설정`** 1회 실행 → 권한 승인
   → 매월 **1일·15일 10시**에 전월 자동 수집 등록
6. **(선택) 지금 채우기**: `정기수집` 실행(전월), 또는 특정 월은 `수집월(2026, 8)`,
   기간 백필은 `수집기간(2026, 1, 2026, 8)`

## 동작

- **1일** 실행 = 전월 첫 수집 / **15일** = 전월 재수집(사후 정정 반영)
- 매 실행마다 해당 월 **정육(소정육·돼지정육·양·염소)** 을 최신값으로 교체 커밋
- 커밋 메시지: `데이터 수집: YYYY-MM-DD (GAS, YYYY-MM)`
- 실행 로그는 Apps Script **실행(Executions)** 탭에서 확인
- 안전장치: 새 데이터가 기존 대비 70%+ 급감하면 교체 중단(API 이상 응답 방지)

## 로컬 예약작업과의 관계

- 이 GAS가 돌면 **로컬 윈도우 PC 예약작업은 더 이상 필요 없다.** (있으면 같은 데이터를
  두 곳에서 밀어 중복 커밋만 생기니, 기존 PC의 예약작업은 해제 권장 — `scripts\예약해제.ps1`)
- 부산물(QIA)은 식약처 API에 없으므로 여전히 `parser.html`로 수동 업로드.
