2GitHub 연결 · 자동 커밋용 (1회 설정)

미연결
토큰 발급 방법 (약 1분)
  1. GitHub → Settings → Developer settings → Fine-grained personal access tokens → Generate new token
  2. Repository access → Only select repositories → 이 저장소 선택
  3. Permissions → Repository permissions → Contents: Read and write (그 외 불필요)
  4. 만료일 지정 후 생성 → github_pat_... 복사해서 위에 붙여넣기
토큰은 이 브라우저에만 저장되고 다른 서버로 전송되지 않습니다(GitHub API로만). 공용 PC라면 "저장" 체크는 끄세요.
