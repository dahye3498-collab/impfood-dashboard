# 수입축산물 검역통계 대시보드

식약처 수입식품정보(impfood.mfds.go.kr)의 수입 축산물 검역 데이터를 매월 자동
수집해 보여주는 대시보드입니다. 기존 Google Apps Script + 구글시트 시스템을
2026-07-10에 재구성했으며, 2016년부터의 이력 전체를 이관했습니다.

| | |
|---|---|
| **대시보드** | https://jun2857.github.io/impfood-dashboard/ |
| 저장소 | github.com/jun2857/impfood-dashboard (비공개 · Pages 페이지는 링크 공개) |
| 로컬 사본 | `C:\dev\impfood-dashboard` |

## 어떻게 돌아가나

```
동준님 PC (한국 IP)                          GitHub
┌──────────────────────────┐   커밋·푸시   ┌───────────────────────┐
│ 윈도우 예약 작업            │  ─────────▶  │ 저장소 (데이터+코드)     │
│ 매월 1일·15일 10:00 수집    │              │  └ Pages → 대시보드     │
└──────────────────────────┘              └───────────────────────┘
```

**⚠ 식약처 API는 해외 IP 요청에 응답하지 않으므로** 수집은 반드시 한국 IP(이 PC)에서
돌아야 합니다. GitHub Actions(미국 러너)로는 불가 — 그래서 수집은 로컬 예약 작업이
맡고, GitHub은 저장·배포만 담당합니다.

- 예약 작업 이름: `impfood-collect-1일`, `impfood-collect-15일` (작업 스케줄러)
- 1일 실행 = 전월 첫 수집, 15일 실행 = 전월 재수집(뒤늦게 정정된 데이터 반영)
- PC가 꺼져 있었으면 **다음 부팅 때 자동으로 밀린 수집을 실행**합니다
- 로그: `logs/collect-연월.log`

## 파일 구조

```
data/quarantine-<연도>.json    연도별 데이터 (레코드: [품명, 구분, 부위, 국가, 검역량kg, 월])
data/manifest.json             연도 목록·갱신일시 (수집기가 자동 관리)
data/fta.json                  FTA 할당관세 — 수동 관리
data/config.json               AI 질문 기능 설정 (ai_endpoint)
index.html                     대시보드 전체 (정적 단일 파일, 빌드 불필요)
scripts/collect.mjs            정육 수집기 (식약처 API, 자동)
scripts/collect-byproducts.mjs 부산물 수집기 (QIA 엑셀 → 해당월 교체, 수동)
scripts/store.mjs              데이터 저장 공통 모듈
scripts/monthly-collect.ps1    예약 작업이 실행하는 스크립트 (수집→커밋→푸시)
scripts/수집실행.cmd            수동 수집 (더블클릭)
scripts/serve.mjs              로컬 미리보기 서버 (node scripts/serve.mjs → :8123)
scripts/migrate.mjs            구글시트 이관용 (일회성, 완료됨)
.github/workflows/collect.yml  수동 실행용으로만 유지 (해외 IP 차단으로 스케줄 불가)
```

## 대시보드 기능

- **이번 달 브리핑** — 최신 월 요약문 자동 생성 + 국가 신호 자동 감지
  (3개월+ 연속 증감 / 전년 동월 ±30% / 신규 원산지 — 월 20t 이상만). 신호 클릭 시 해당 국가로 필터.
- **추이 차트 3모드** — 연도 비교(연도 칩으로 최대 4개 직접 선택) / 국가 비교(최근
  24개월 상위 4개국) / 장기 추세(12개월 이동합 — 계절성 제거한 구조 추세)
- **계절성 히트맵** — 최근 10개년 연도×월 매트릭스 + 평년(최근 5개 완결 연도 평균)
  행 + 이번 달 평년 대비 편차 배지(±15%). 색 범례 포함 — 색은 표 안의 최댓값 대비
  비율이라 필터가 다르면 진하기를 서로 비교할 수 없음.
- **구성 비중 추이** — 국가/부위/구분 차원 토글, 최근 6개년 100% 누적 바 + 집중도(HHI)
- **월 상세 드릴다운** — 월별 표·히트맵 셀 클릭 → 그 달의 국가별·부위별 분해 + 전년
  동월 증감 모달. 국가별 바 클릭 → 국가 필터. 표 연도 헤더 클릭 → 비교에서 제외.
- **FTA 소진 페이스 예측** — 사용률·기준일(as_of) 기반 선형 추정, 소진 60일 전 경고색
- **CSV 내려받기 · 표 복사** — 엑셀 호환(한글 BOM), 파일명에 필터·기준월 자동 포함
- **링크 공유 · 즐겨찾기** — 필터·차트 모드가 URL에 담김. 마지막 화면 자동 복원,
  자주 쓰는 조합은 칩으로 저장 (복원·즐겨찾기는 브라우저별 저장이라 기기마다 따로)
- **인쇄 리포트 모드** — [인쇄] 버튼 → A4 월간 보고서 (브라우저에서 PDF 저장 가능)
- **AI 질문** — `data/config.json`의 `ai_endpoint`에 GAS 웹앱 URL(…/exec)을 넣으면
  카드가 나타남. 현재 필터의 데이터 요약이 질문에 자동 첨부됨. 키는 GAS 서버 쪽에 보관.

## 수집 규칙

- 소고기→소정육, 돼지고기→돼지정육: 냉동·냉장만, 부위별 저장
- 양고기→양, 염소고기→염소: 냉동·냉장만, 부위 '전체'로 합산
- 중복 키: 품명+구분+부위+국가+월 (구분 포함 — 구 GAS의 냉동/냉장 누락 버그 수정됨)
- `--replace` 안전장치: 새 데이터가 기존 대비 70% 이상 급감하면 교체를 중단
  (API 이상 응답으로부터 보호). 부산물 등 수동 데이터는 교체 대상에서 제외.

수동 실행:

```
node scripts/collect.mjs                              # 전월 수집
node scripts/collect.mjs --from 2024-01 --to 2024-12  # 기간 백필
node scripts/collect.mjs --from 2025-03 --replace     # 지우고 재수집
```

### ⚠ API 컬럼 함정

`wtCnt6` = 조회기간 내 검역량, `wtCnt7` = **연초부터의 누계** (wtCnt7 = wtCnt2 +
wtCnt6). 1월에는 둘이 같아서 혼동하기 쉽습니다. 구 GAS 백필이 wtCnt7을 써서
양·염소 2024~25 데이터가 오염됐던 전력이 있고, 재구성 때 재수집으로 정화했습니다.

### 데이터 정합성 참고

- 검역 데이터는 **사후 정정이 큽니다** (월초 집계 대비 +20%까지 관측됨) — 15일
  재수집이 이를 반영합니다.
- 2016~2023년은 구 시트의 "당시 월초 집계값", 2024년 이후는 "API 최신 정정값"
  기준입니다. 과거 연도도 최신값으로 통일하려면 해당 기간을 `--replace`로 재수집하면
  되지만, 예전 보고서에 쓴 숫자와 달라질 수 있어 일부러 하지 않았습니다.

## 수동 관리 데이터

- **FTA 할당관세** (`data/fta.json`): GitHub에서 직접 수정 → 자동 반영.
  **사용률(usage_pct)을 갱신할 때 확인 날짜(as_of)도 함께 수정**해야 소진 예측이 맞습니다.
- **소부산물·돼지부산물**: 식약처 API에 없어 자동 수집 불가. 농림축산검역본부 QIA
  (https://eminwon.qia.go.kr/statistics/statistics_No2.do)에서 매달 수동 반영한다.
  1. QIA: 통계분류=수입축산물, 품목=육류, **검사기간=해당월~해당월(반드시 단월)** → 엑셀 다운로드
  2. `node scripts/collect-byproducts.mjs <다운받은.xls> <연도> <월>` (미리보기는 `--dry`)
  3. `git add data && git commit && git push`
  - ⚠ 검사기간을 단월로 두지 않으면 누계(YTD)가 그 달 값으로 들어가 오염된다(스크립트가 자동 차단).
  - 추적 부위: (소) 안창토시·우건·꼬리·볼살·깐양홍창·곱창대창·뼈 / (돼지) 갈매기·돼지머리·장족단족·목뼈등뼈·곱창막창.
    QIA 품명↔부위 매핑은 스크립트 상단에 있음. 물량 적은 부위(우족·소간·소심장 등)는 의도적으로 제외.

## 인수인계 — 새 담당자 셋업 (약 15분)

수집은 반드시 **한국 IP의 윈도우 PC**에서 돌아야 합니다. 새 담당자 PC에서:

1. **설치**: [Node.js](https://nodejs.org) (LTS), [Git](https://git-scm.com), [GitHub CLI](https://cli.github.com)
2. **GitHub 로그인**: PowerShell에서 `gh auth login` (본인 GitHub 계정, HTTPS 선택)
3. **저장소 받기**: `gh repo clone <소유자>/impfood-dashboard` (원하는 폴더에서)
4. **자동 수집 등록**: 저장소 폴더에서 `.\scripts\예약등록.ps1` 실행
   → 매월 1일·15일 10:00 자동 수집이 등록됨 (클론 위치가 어디든 동작)
5. **테스트**: `scripts\수집실행.cmd` 더블클릭 → `logs\` 폴더에 "완료" 로그 확인

저장소 소유권 이전(기존 소유자 GitHub → Settings → General → Danger Zone →
Transfer ownership) 후에는:

- 새 소유자 계정에서 **Settings → Pages**가 켜져 있는지 확인 (branch: main, / root)
- **대시보드 주소가 바뀝니다**: `<새소유자>.github.io/impfood-dashboard` — 북마크 공지 필요
- ⚠ 새 소유자가 무료 플랜이면 비공개 저장소로는 Pages를 못 씁니다 — 저장소를
  공개로 전환하거나(데이터는 공공 통계라 무방) 유료 플랜 필요

기존 PC 정리: 저장소 폴더에서 `.\scripts\예약해제.ps1` 실행 (예약 작업 삭제) 후 폴더 삭제.

## 문제가 생기면

| 증상 | 확인 |
|---|---|
| 대시보드 "갱신" 날짜가 오래됨 | 수집이 안 돌고 있음 — `logs/` 최신 로그 확인, `scripts\수집실행.cmd` 더블클릭으로 수동 수집 |
| 수집 로그에 "교체 중단" | 안전장치 발동 — API 응답이 비정상적으로 적었음. 다음 정기 수집을 기다리거나 데이터 확인 후 재실행 |
| 수집 로그에 "재시도/수집 실패" | 식약처 서버 점검 가능성 — 나중에 수동 재실행 |
| AI 카드가 안 보임 | `data/config.json`의 `ai_endpoint`가 비어 있음 (GAS 배포 URL 필요) |
