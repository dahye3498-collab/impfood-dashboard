# 수입축산물 검역통계 대시보드

식약처 수입식품정보(impfood.mfds.go.kr)의 수입 축산물 검역 데이터를 매월 자동
수집해 보여주는 대시보드입니다. 기존 Google Apps Script + 구글시트 시스템을
2026-07-10에 재구성했으며, 2016년부터의 이력 전체를 이관했습니다.

| | |
|---|---|
| **대시보드** | https://dahye3498-collab.github.io/impfood-dashboard/ |
| 저장소 | github.com/dahye3498-collab/impfood-dashboard (Pages 링크 공개) |
| 부산물 업로드 | `…/impfood-dashboard/parser.html` (담당자용) |

## 어떻게 돌아가나

데이터를 저장소에 JSON으로 커밋하면 GitHub Pages가 그대로 대시보드로 배포합니다.
**수집은 로컬 PC 없이** 두 경로로 들어옵니다:

```
정육 (소·돼지·양·염소)                        GitHub                      부산물 (소·돼지)
┌────────────────────────┐                ┌──────────────┐             ┌────────────────────────┐
│ Google Apps Script     │  ── 커밋 ──▶   │ data/*.json  │  ◀── 커밋 ── │ parser.html (브라우저)   │
│ 매월 1·15일 식약처 API   │                │  Pages→대시보드│             │ QIA 엑셀 드래그→업로드    │
└────────────────────────┘                └──────────────┘             └────────────────────────┘
      (구글 서버, 자동)                                                   (담당자, 월 1회 수동)
```

**⚠ 식약처 API는 해외 IP 요청에 응답하지 않습니다.** GitHub Actions(미국 러너)로는 불가.
그래서:

- **정육**: **Google Apps Script**가 구글 서버에서 식약처 API를 호출(구 GAS 시스템도 이 방식)
  → `data/quarantine-<연도>.json`에 **직접 커밋**. 매월 1·15일 자동. 셋업·상세:
  [`google-apps-script/`](google-apps-script/). (1일=전월 첫 수집, 15일=재수집으로 사후정정 반영)
- **부산물**: 식약처 API에 없어 QIA 엑셀을 받아 **`parser.html`**(브라우저)로 업로드 → 자동 커밋.
- 두 경로 모두 **로컬 윈도우 PC·예약작업이 필요 없습니다.** (구 로컬 Node 방식은 아래 "대안"에 남겨둠.)


## 대시보드 기능

상단 필터(품명·구분·부위·국가)는 모든 탭 공통. 상단에 **페이지 탭 3개**:
**[종합 대시보드]** / **[국가별 월별 검역량]** / **[부위별 월별 검역량]** (활성 탭은 URL·브라우저에 저장).

### 종합 대시보드
- **이번 달 브리핑** — 최신 월 요약문 자동 생성 + 국가 신호 자동 감지
  (3개월+ 연속 증감 / 전년 동월 ±30% / 신규 원산지 — 월 20t 이상만). 신호 클릭 시 해당 국가로 필터.
- **검역량 추이** — 연도 비교 라인 차트(연도 칩으로 **최대 5개** 직접 선택) + 평년(최근 5개
  완결 연도 평균) 점선 기준선. (예전의 국가 비교·장기 추세 모드 탭은 제거됨)
- **국가별 검역량** — 최근 12개월 상위 국가 막대(클릭 → 국가 필터) · **연도별 합계** 차트
- **월별 상세** — 최근 **3개년** 월×연도 표(톤). 셀 클릭 → 월 상세 드릴다운. 연도 헤더 가운데 정렬.
- **계절성 히트맵** — 최근 10개년 연도×월 매트릭스 + 평년 행 + 이번 달 평년 대비 편차 배지(±15%).
  색은 표 안 최댓값 대비 비율이라 필터가 다르면 진하기를 서로 비교할 수 없음.
- **구성 비중 추이** — 국가/부위/구분 차원 토글, 최근 6개년 100% 누적 바 + 집중도(HHI)
- **FTA 소진 페이스 예측** — 사용률·기준일(as_of) 기반 선형 추정, 소진 60일 전 경고색
- **월 상세 드릴다운** — 월별 표·히트맵 셀 클릭 → 그 달의 국가별·부위별 분해 + 전년 동월 증감 모달.

### 국가별 월별 검역량 (탭)
선택한 품명·부위 기준으로 **국가(행)×월(열) 원본 수치(kg)** 를 **최근 3개년** 블록으로 표시
(소계·합계·월평균 실적월). 국가명 클릭 → 해당 국가로 필터, 복사·CSV 지원.
(구 quarantine 대시보드의 피벗 표와 동일한 보기.)

### 부위별 월별 검역량 (탭)
같은 형식으로 **부위(행)×월(열)** — 부위 필터는 무시하고 전 부위를 나열(품명·구분·국가 필터는 반영)
해 **부위 간 비교**. 최근 3개년, 부위명 클릭 → 해당 부위로 필터, 복사·CSV.

### 공통
- **CSV 내려받기 · 표 복사** — 표마다 제공, 엑셀 호환(한글 BOM), 파일명에 필터·기준월 자동 포함.
  원본 CSV(전 품목)도 별도 제공.
- **링크 공유 · 즐겨찾기** — 필터·활성 탭이 URL에 담김. 마지막 화면 자동 복원,
  자주 쓰는 조합은 칩으로 저장 (복원·즐겨찾기는 브라우저별 저장이라 기기마다 따로)
- **인쇄 리포트 모드** — [인쇄] 버튼 → A4 월간 보고서 (브라우저에서 PDF 저장 가능)
- **담당자용 '부산물 업로드' 링크** — 주소 뒤 `#admin`을 한 번 열면 상단바에 `parser.html`
  바로가기가 나타남(그 브라우저에만 저장, 일반 방문자엔 안 보임). 끄기는 `#admin=off`.
- **AI 질문 (선택)** — `data/config.json`의 `ai_endpoint`에 GAS 웹앱 URL(…/exec)을 넣으면
  카드가 나타남. 현재 필터의 데이터 요약이 질문에 자동 첨부됨. 키는 GAS 서버 쪽에 보관.

## 수집 규칙

- 소고기→소정육, 돼지고기→돼지정육: 냉동·냉장만, 부위별 저장
- 양고기→양, 염소고기→염소: 냉동·냉장만, 부위 '전체'로 합산
- 중복 키: 품명+구분+부위+국가+월 (구분 포함 — 구 GAS의 냉동/냉장 누락 버그 수정됨)
- 교체 안전장치: 새 데이터가 기존 대비 70% 이상 급감하면 교체를 중단(API 이상 응답 보호).
  해당 월의 **정육만 교체**하고 부산물 등은 건드리지 않음.

위 규칙은 **GAS(`google-apps-script/Code.gs`)와 로컬 `collect.mjs`가 동일**하게 적용합니다.
정육은 GAS 자동수집이 기본이며, 로컬 Node는 대안:

```
node scripts/collect.mjs                              # 전월 수집
node scripts/collect.mjs --from 2024-01 --to 2024-12  # 기간 백필
node scripts/collect.mjs --from 2025-03 --replace     # 지우고 재수집
```
(GAS에서는 `정기수집`=전월 / `수집월(연,월)` / `수집기간(...)` 함수로 동일 동작.)

### ⚠ API 컬럼 함정

`wtCnt6` = 조회기간 내 검역량, `wtCnt7` = **연초부터의 누계** (wtCnt7 = wtCnt2 +
wtCnt6). 1월에는 둘이 같아서 혼동하기 쉽습니다. 구 GAS 백필이 wtCnt7을 써서
양·염소 2024~25 데이터가 오염됐던 전력이 있고, 재구성 때 재수집으로 정화했습니다.

### 데이터 정합성 참고

- 검역 데이터는 **사후 정정이 큽니다** (월초 집계 대비 +20%까지 관측됨) — 15일
  재수집이 이를 반영합니다.
- 2016~2023년은 구 시트의 "당시 월초 집계값", 2024년 이후는 "API 최신 정정값"
  기준입니다. 과거 연도도 최신값으로 통일하려면 해당 기간을 `--replace`로 재수집하면
  되지만, 예전 보고서에 쓴 숫자와 달라질 수 있어 일부러 하지 않았습니다.
- 검역량 0 레코드는 저장하지 않습니다(수집 규칙 `kg<=0` 제외와 동일). 구 시트 이관분에
  섞여 있던 0kg 레코드 11,740건(2016~2023 중심)은 일괄 정리했습니다 — 톤수 합계엔
  영향이 없으나 국가 수·신규 원산지 신호·집중도(HHI) 계산 왜곡을 막기 위함입니다.
- 부산물은 초기 배치가 **과소입력**될 수 있어(단월이 아닌 조회 등), 이상하게 낮거나 특정
  부위가 비면 QIA 단월 엑셀로 재수집·교체합니다. (예: 2026-03·04·05 소부산물 '뼈' 누락 복구)

## 수동 관리 데이터

- **FTA 할당관세** (`data/fta.json`): GitHub에서 직접 수정 → 자동 반영.
  **사용률(usage_pct)을 갱신할 때 확인 날짜(as_of)도 함께 수정**해야 소진 예측이 맞습니다.
- **소부산물·돼지부산물**: 식약처 API에 없어 자동 수집 불가. 농림축산검역본부 QIA
  (https://eminwon.qia.go.kr/statistics/statistics_No2.do)에서 매달 수동 반영한다.
  QIA 다운로드: 통계분류=수입축산물, 품목=육류, **품목·국가별 수출입현황**,
  **검사기간=해당월~해당월(반드시 단월)** → 엑셀 다운로드. 이후 두 방법 중 하나:

  **방법 A — 브라우저 파서 (설치·명령어 불필요, 담당자 권장)**
  0. (선택) 대시보드에 담당자용 바로가기: 대시보드 주소 뒤 `#admin` 을 한 번 열면
     상단바에 **"부산물 업로드"** 링크가 나타남(그 브라우저에만 저장·표시, 일반 방문자엔 안 보임).
     끄기는 `#admin=off`. 파서에 토큰을 저장해둔 브라우저는 자동으로 보임.
  1. 대시보드 주소 뒤에 `/parser.html` (예: `<소유자>.github.io/impfood-dashboard/parser.html`) 열기
  2. 받은 엑셀을 드래그&드롭 → 연·월 자동 인식 + 파싱·검증 미리보기
  3. 반영: 두 가지 중 하나
     - **자동 커밋(권장)**: "GitHub 연결"에 파인그레인드 토큰(이 저장소·Contents 쓰기)을
       1회 저장 → **[GitHub에 바로 커밋]** 한 번이면 `data/` 두 파일을 한 커밋으로
       올리고 1분 내 자동 반영. 토큰은 그 브라우저에만 저장(개인 PC 권장, "토큰 지우기" 버튼 있음).
     - **수동**: `quarantine-<연도>.json`(과 `manifest.json`) 다운로드 → GitHub `data/`에 덮어쓰기 커밋
     - (파서 결과는 아래 스크립트와 바이트 단위 100% 동일)

  **방법 B — 로컬 스크립트 (Node 환경)**
  1. `node scripts/collect-byproducts.mjs <다운받은.xls> <연도> <월>` (미리보기는 `--dry`)
  2. `git add data && git commit && git push`
  - ⚠ 검사기간을 단월로 두지 않으면 누계(YTD)가 그 달 값으로 들어가 오염된다(파서·스크립트 모두 자동 차단).
  - 추적 부위: (소) 안창토시·우건·꼬리·볼살·깐양홍창·곱창대창·뼈 / (돼지) 갈매기·돼지머리·장족단족·목뼈등뼈·곱창막창.
    QIA 품명↔부위 매핑은 스크립트 상단에 있음. 물량 적은 부위(우족·소간·소심장 등)는 의도적으로 제외.

## 인수인계 — 새 담당자 셋업

로컬 PC 없이 브라우저·구글 계정만으로 운영합니다.

**1. 정육 자동수집 (GAS) — 약 10분, 최초 1회**
[`google-apps-script/README.md`](google-apps-script/README.md) 참고. 요약:
- GitHub 파인그레인드 토큰(이 저장소·Contents 쓰기) 발급
- script.google.com 새 프로젝트에 `Code.gs` 붙여넣기 → 스크립트 속성 `GH_TOKEN` 등록 → 시간대 서울
- `트리거설정` 실행 → 매월 1·15일 자동. (밀린 달은 `정기수집`/`수집월(연,월)`로 채움)

**2. 부산물 반영 (parser.html) — 월 1회**
QIA 단월 엑셀을 `parser.html`에 드래그 → 토큰 저장해두면 [GitHub에 바로 커밋] (아래 "수동 관리 데이터" 참고).

**소유권 이전 시** (Settings → General → Danger Zone → Transfer ownership):
- 새 소유자 계정에서 **Settings → Pages** 켜짐 확인 (branch: main, / root)
- **대시보드 주소가 바뀜**: `<새소유자>.github.io/impfood-dashboard` — 북마크 공지 필요
- ⚠ 무료 플랜은 비공개 저장소로 Pages 불가 — 공개 전환(데이터는 공공 통계라 무방)하거나 유료 플랜
- GAS의 `GH_TOKEN`·owner도 새 소유자 기준으로 갱신 (`Code.gs` 상단 `GH_OWNER`)
